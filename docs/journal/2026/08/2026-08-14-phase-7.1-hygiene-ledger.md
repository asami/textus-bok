## P7.1-HY-01: External Descriptor Helper Uses the Legacy Contract

Disposition: external tooling hygiene follow-up.

Evidence: normal `cncf-car-lint` reports `car-descriptor.contract` because its
Python helper expects root `name` and `component` fields. The built CAR contains
the canonical schema-v3 descriptor with
`component.{namespace,id,version}`. Cozy's current packager accepts that shape,
`cozyBuildCAR` succeeds, and integrated Cozy lint reports
`CAR_COMPONENT_IDENTITY_CANONICAL` for `org.simplemodeling.textus.Bok`.

Risk: the outer lint summary remains noisy and can obscure a real future CAR
failure even though the current archive identity is valid.

Follow-up boundary: update the external `cncf-car-lint` descriptor helper to
recognize canonical schema v3. Do not add rejected legacy root fields to the
CAR or reopen Phase 7.1.

## P7.1-HY-02: Historical Probe and Example Identity Drift

Disposition: integration-asset hygiene follow-up.

Evidence: historical scripts and examples still contain unqualified
`Bok.BokRetrieval.*` names, a lowercase `tool.` partition, or
`cncf.component-repository-index.v1` fixtures. The current public operation
names are `org.simplemodeling.textus.Bok.BokRetrieval.*`, platform tools are
qualified under `org.goldenport.cncf.Tool`, and the repository index is v2.
Phase 4 documentation preserves the historical names used by that closed
Phase.

Risk: rerunning an old representative probe without migration can fail before
it reaches the behavior it intends to demonstrate.

Follow-up boundary: migrate each representative probe and example as a
coherent integration task with its own runtime evidence. Do not mix that work
into the private P7-B registry/resolver closure.

## P7.1-HY-03: Pre-existing Generated Help Joining

Disposition: CML/generator hygiene follow-up.

Evidence: the descriptions changed by the canonical-identity repair are now
single physical CML lines and generate correct spaces. An unchanged older
multiline description at CML lines 191–192 still generates `Thispublic` in one
help summary. It predates the Phase 7.1 repair and was classified as existing
debt by the final focused re-review.

Risk: one public help sentence is cosmetically malformed.

Follow-up boundary: repair the older description, or the generator's general
line-joining policy, in a dedicated documentation/CML hygiene change.
